# Hanchat 플러그인

### 마인크래프트 1.21.1X 버전용 한글채팅 플러그인
<br>

기존에 alt(한/영)키를 눌러 채팅시 한글 입력 상태에서 키보드의 이동이 먹히지 않는 문제 대응


한글 입력 방식 : gksrmfcoxld => 한글채팅 으로 변환<br>
테스트 버전 : 1.21.11 버전<br>
호환 버킷 : paper 전용<br>
현재버전 : 1.0

---
### 사용법
1. 플러그인을 plugins 폴더에 넣음
2. 서버 실행
3. /ko 입력시 한글채팅 활성화
4. 다시 /ko 입력시 한글채팅 비활성화
